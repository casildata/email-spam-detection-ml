# Data

## `raw/spambase.csv`

UCI Spambase: 4,601 emails (39.4% spam) × 57 numeric features (word and character frequencies, runs of capital letters) plus the `spam` label.

- **Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/94/spambase)
- **License:** CC BY 4.0
- **Citation:** Hopkins, M., Reeber, E., Forman, G., & Suermondt, J. (1999). *Spambase* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C53G6X
